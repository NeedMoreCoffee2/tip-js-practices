## 4. Модель данных и функции

**Поля задачи:**
- `id` - Уникальный числовой идентификатор задачи.
- `title` - Текст названия задачи.
- `completed` - Булево, выполнена ли задача.
- `priority` - Приоритет: `low` / `medium` / `high`.

**Правила валидации:**
- `id` - Обязательно число больше нуля, уникален в пределах массива.
- `title` - Непустая строка.
- `completed` - `true` или `false`. Тип `boolean`.
- `priority` - Приоритет: `low` / `medium` / `high`. По умолчанию `medium`.

**Назначение файлов:**
- `functions-and-references.js` - Эксперименты.
- `data.js` - Стартовый массив задач и вариант.
- `task-service.js` - Реализация экспортных функций(ES-модули), операции над массивом.
- `main.js` - главное не забыть заполнить потом главное не забыть заполнить потом главное не забыть заполнить потом!!!!!!!!!!!!!!!!!!
- `checks.js` - Проверки реализации функций из `task-service.js`.
- `package.json` - Скрипты для `npm`.

| Функция            | Успех                                                         | Ошибка                                         |
| :----------------- | :------------------------------------------------------------ | :----------------------------                  |
| `createTask`       | `{ ok: true, task: {id, title, completed: false, priority} }` | `{ ok: false, error: "..." }`                  |
| `findTaskById`     | `{id, title, completed, priority}`                            | `undefined`                                    |
| `getPendingTasks`  | массив невыполненных задач c `completed = false`              | Если нет `completed = false`, то пустой массив |
| `getTaskTitles`    | массив, состоящий только из `title` всех элементов            | Если нет элементов - пустой массив             |
| `getTaskStats`     | `{ total, completed, pending, progress }`                     | Если `completed` равняется 0, то возвращаем `0`|
| `addTask`          | `{ ok: true, tasks: новыйМассив }` - c новой задачей          | `{ ok: false, error: "..." }`                  |
| `setTaskCompleted` | `{ ok: true, tasks: newTasks }` - с изменённым `completed`    | `{ ok: false, error: "..." }`                  |
| `renameTask`       | `{ ok: true, tasks: newTasks }` - с переименованным элементом | `{ ok: false, error: "..." }`                  |
| `removeTask`       | `{ ok: true, tasks: newTasks }` - без удалённого элемента     | `{ ok: false, error: "..." }`                  |

**Почему id не равен индексу:** id - это идентичность сущности, индекс - это место в массиве.  
**Почему getTaskStats возвращает число, а не строку с процентом:** Число можно переиспользовать: сравнить, отсортировать, подставить в другую формулу. А строку "50%" нельзя сложить с другой.  
**Какие объекты копируются при изменении задачи:** Копируется сам массив (`[...tasks]`, `map`, `filter` создают новый массив).
